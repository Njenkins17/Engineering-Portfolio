# Mechanical Engineering Portfolio — Noah Jenkins

Static website built for GitHub Pages.

## Publish to GitHub Pages

1. Create a public GitHub repository named `engineering-portfolio` (or another name).
2. Upload `index.html` and the entire `images/` folder to the repository root.
3. Go to repository **Settings > Pages**. Under **Build and deployment**, select **Deploy from a branch**, `main`, and `/ (root)`; save.
4. Your site URL will usually be `https://YOUR-USERNAME.github.io/engineering-portfolio/`.
5. Future updates: replace images or edit index.html in the same repo; the URL stays the same.
